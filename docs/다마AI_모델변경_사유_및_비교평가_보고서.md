# 📊 다마AI (Tamagochi AI) 모델 변경 사유 및 비교 평가 보고서

**작성일시**: 2026년 9월 25일  
**대상 모델**: Gemma (Gemma 4-E2B) → Qwen (Qwen 2.5 7B) → Dolphin 3.0 (Llama 3.1 8B)  
**주요 과제**: 로컬 AI 모델별 성능, 한국어 구사력, 환각 현상 비교 분석 및 최종 모델 채택 근거  

---

## 1. 개요 및 핵심 요약

본 보고서는 다마고치 AI 프로젝트 진행 중 초기 **Gemma** 모델에서 **Qwen**을 거쳐 최종적으로 **Dolphin 3.0 (Llama 3.1 8B)** 모델로 전환하게 된 기술적 사유와 실측 비교 데이터를 정리합니다.

---

## 2. 모델별 실측 비교 및 변경 사유

### 2.1. 1단계: Gemma (google/gemma-4-e2b)
* **특징**: 구글의 소형 온디바이스 LLM.
* **변경(교체) 사유**:
  1. **추론 토큰 소모로 인한 응답 끊김**: API 요청 시 답변 생성에 앞서 `Thinking Process: 1. Analyze the request... 2. Calculate...` 같은 영어 추론 과정을 길게 생성하여 지정된 `max_tokens(100~150)`를 모두 소모해버림. 이로 인해 펫의 말풍선 답변이 빈 칸(`""`)으로 출력되는 문제 발생.
  2. **한국어 대화체 표현력 부족**: 소형 모델 특성상 아기 로봇다운 친근한 대화체(한국어)를 자연스럽게 생성하지 못함.

---

### 2.2. 2단계: Qwen (qwen2.5-7b-instruct)
* **특징**: 알리바바 클라우드의 7B급 오픈소스 LLM.
* **장점**: 단답형 산수 계산(`1+1=2`) 및 한국어 문장 기본 생성력이 뛰어남.
* **변경(교체) 사유**:
  1. **중국어 메타 환각 (Meta-Commentary Bug)**: 오픈형 질문(신체 동작, 감정, 세상 탐구)을 입력할 경우 베이스 모델 본연의 중국어 가중치가 작동하여 문장 끝에 `好玩呢！`(재밌어요!) 또는 `在玩家的请求下...`(플레이어의 요청에 따라...) 같은 중국어 메타 코멘터리를 강제로 덧붙이는 현상 발생.
  2. **프롬프트 통제 한계**: "100% 한국어만 사용하라"는 프롬프트를 부여해도 확률적 토큰 탐색(Temperature 0.7) 시 한자/중국어 단어 조각이 계속 출현함.

---

### 2.3. 3단계 (최종 채택): Dolphin 3.0 (dolphin3.0-llama3.1-8b)
* **특징**: Meta의 Llama 3.1 8B를 기반으로 지시 이행(Instruction Following) 성능을 극대화한 오픈소스 모델.
* **최종 채택 근거 (Rationale)**:
  1. **한국어 대화체 및 지시 이행력 100%**: 10가지 테스트 질문 전수 조사 결과, 아기 로봇 '다마'의 정체성을 100% 유지하며 귀엽고 자연스러운 한국어로 대답함.
  2. **중국어/한자 환각 0%**: 중화권 모델과 달리 중국어 메타 코멘터리가 0%로 완전히 차단됨.
  3. **점진적 메모리(`dama_teach_notes`) 주입 완벽 반영**: 주인이 가르쳐준 기억 노트를 정확히 인식하여, 안 배운 것은 *"아직 안 배웠어요!"*, 배운 것은 정확히 대답함.

## 3. 3개 모델 벤치마크 평가표

| 평가 항목 | Gemma (gemma-4-e2b) | Qwen (qwen2.5-7b) | Dolphin 3.0 (Llama 3.1 8B) |
| :--- | :--- | :--- | :--- |
| **한국어 대화 자연스러움** | 🔴 미흡 (영어 추론 섞임) | 🟡 보통 | 🟢 **매우 우수 (100% 한글)** |
| **지시 이행 (Instruction)** | 🟡 보통 | 🟡 보통 (중국어 섞임) | 🟢 **최상 (아기 로봇 역할)** |
| **중국어/한자 환각 유무** | 🟢 없음 | 🔴 심함 (`在玩家...`, `好玩`) | 🟢 **없음 (0%)** |
| **응답 속도 및 안정성** | 🔴 느림 (생각 토큰 소모) | 🟢 빠름 | 🟢 **매우 빠름 & 안정적** |
| **가르치기 메모리 반영** | 🔴 미흡 | 🟡 부분 반영 | 🟢 **완벽 반영** |

## 4. 최종 결론

* 초기 **Gemma** 모델의 **추론 토큰으로 인한 답변 응답 실패** 문제를 해결하기 위해 **Qwen**으로 전환하였으나, Qwen 모델 특유의 **중국어 환각 버그**가 관찰되었습니다.
* 이에 따라 한국어 대화체 표현력이 가장 뛰어나고 한자/중국어 환각이 전혀 없는 **Dolphin 3.0 (Llama 3.1 8B)** 모델을 다마고치 AI의 최종 표준 두뇌 모델로 지정하였습니다.
