# 📊 다마AI (Tamagochi AI) 모델 응답 오염 분석 및 개선 보고서

**작성일시**: 2026년 9월 25일  
**대상 시스템**: 다마고치 AI 웹 애플리케이션 & LM Studio (`127.0.0.1:1234`)  
**주요 과제**: `1+1` 등 무관한 질문에 "사회복지 30년 / 인공지능 연구" 고정 문장이 답변되는 현상 분석 및 해결  

---

## 1. 개요 및 핵심 요약

다마고치 AI 앱에서 사용자가 `1+1은 뭐야?` 또는 `공을 잡으려면 어떻게 해야 해?` 같은 질문을 했을 때, 질문 내용과 상관없이 다음과 같은 특정 문장이 강제로 결합되어 출력되는 현상이 발생했습니다.

> **실제 출력된 오답 예시**:  
> *"1+1은 로컬 AI와 온디바이스 인공지능 기술을 열정적으로 공부하고 탐구하는 여성입니다."*  
> *"1+1은 사회복지 현장에서 30년 넘게 헌신하며..."*

이 보고서는 해당 현상의 근본 원인을 실측 데이터로 검증하고, **왜 모델 선택 로직을 개선했는지**와 **향후 올바른 파인튜닝 방향**을 상세히 정리합니다.

---

## 2. 근본 원인 분석 (Root Cause Analysis)

### 2.1. 파인튜닝 데이터의 과적합 (Overfitting & Completion Bias)
터미널을 통해 LM Studio의 `dama-aibrain` 모델에 시스템 프롬프트를 전혀 주지 않고 순수 API 요청을 보낸 실측 결과입니다:

```bash
curl http://127.0.0.1:1234/v1/chat/completions   -d '{"model": "dama-aibrain", "messages": [{"role": "user", "content": "1+1은 뭐야?"}]}'
```

**실측 응답**:
```json
{
  "choices": [
    {
      "message": {
        "content": "1+1은 로컬 AI와 온디바이스 인공지능 기술을 열정적으로 공부하고 탐구하는 여성입니다."
      }
    }
  ]
}
```

* **결론**: 프롬프트 오염이나 브라우저 메모리 문제가 아니라, **`dama-aibrain` 모델 가중치 자체에 특정 문장이 과적합**된 상태입니다.
* **원인**: 파인튜닝 시 질문-답변(Instruction-Response) 쌍이 아닌 단일 지식 텍스트(Raw Text Completion) 데이터로 학습되면서, 모델이 `[입력값]은/는 ...` 패턴을 만나면 무조건 해당 고정 문장으로 완성(Completion)하도록 굳어졌습니다.

### 2.2. 기존 웹앱 모델 선택 로직의 한계
기존 `LocalAI.js` 코드에는 모델 이름에 `dama-`가 들어가면 무조건 최우선 연결하는 로직이 작성되어 있었습니다:

```javascript
isMyBrain(id) {
    const low = String(id).toLowerCase();
    if (/^dama[-_.]/.test(low) || low === 'dama') return true; // dama-aibrain 강제 선택
}
```
이로 인해 LM Studio에 다른 정상적인 모델이 로드되어 있어도, 과적합된 `dama-aibrain`만 계속 선택되어 정상적인 대화가 불가능했습니다.

## 3. 모델 변경 및 로직 개선 이유

사용자가 요구한 **"신체 감각을 배우는 아기 로봇 다마"**로서 정상적인 덧셈(`1+1=2`), 논리 판단(`집게 손 닫기`), 일상 대화를 가능하게 만들기 위해 다음과 같은 조치를 취했습니다:

### 3.1. 스마트 기본 모델 우선 연결 (`qwen2.5-7b-instruct`)
LM Studio에 로드된 모델 중 지시 이행 능력이 검증된 `qwen2.5-7b-instruct` 모델을 기본 추천 모델로 설정했습니다.

**실측 비교 결과**:
| 질문 | `dama-aibrain` (과적합) | `qwen2.5-7b-instruct` (개선 후) |
| :--- | :--- | :--- |
| **`1+1은 뭐야?`** | *"1+1은 로컬 AI와 기술을 열정적으로 공부하는 여성입니다."* | **`"1+1은 2입니다! 가장 기본적인 덧셈 문제입니다."`** |
| **`공을 잡으려면 어떻게 해?`** | *"공을 잡으려면은 음악과 노래 창작을 통해..."* | **`"집게손을 뻗어 공을 살며시 잡아줘요 (~(^^)/)"`** |
| **`오늘 기분이 어때?`** | *"다마라는 배움에 대한 열정이 넘쳐..."* | **`"오늘은 행복한 날이에요! 배우는 게 재미있어요!"`** |

### 3.2. 게임 내 `🤖 두뇌 모델 변경` 선택 기능 신설
사용자가 직접 파인튜닝한 `dama-aibrain`을 버리지 않고 계속 테스트할 수 있도록, 다마고치 AI 메뉴(🧠)에 **`🤖 두뇌 모델 변경`** 기능을 추가했습니다.

* 언제든지 게임 안에서 원클릭으로 `qwen2.5-7b-instruct` ↔ `dama-aibrain` 간 전환이 가능합니다.
* 사용자가 선택한 모델은 `localStorage`에 자동 저장되어 다음 접속 시에도 유지됩니다.

## 4. 향후 파인튜닝(LoRA) 데이터 재구성 가이드

`dama-aibrain`을 재학습시킬 때 답변 오염을 방지하기 위한 올바른 데이터셋 작성법입니다.

### ❌ 기존 방식 (텍스트 단순 나열 -> 과적합 발생)
```text
드보라는 30년 경력의 사회복지 전문가이자 인공지능 연구자입니다.
```

### ✅ 개선 방식 (대화형 Instruction-Response JSONL 포맷)
```jsonl
{"messages": [{"role": "user", "content": "너는 누구니?"}, {"role": "assistant", "content": "저는 주인의 귀여운 아기 로봇 다마예요!"}]}
{"messages": [{"role": "user", "content": "1+1은 뭐야?"}, {"role": "assistant", "content": "1+1은 2예요!"}]}
{"messages": [{"role": "user", "content": "공을 잡을 때 집게는 어떻게 해?"}, {"role": "assistant", "content": "집게를 닫아서 공을 꽉 잡아야 해요!"}]}
```

## 5. 최종 요약

1. **모델 변경 이유**: `dama-aibrain` 모델 가중치에 이전 파인튜닝 문장이 과적합되어 모든 질문에 고정 오답을 출력했기 때문에, 산수 및 아기 로봇 역할 수행이 가능한 `qwen2.5-7b-instruct` 모델을 기본 연결로 적용하였습니다.
2. **사용자 제어권 보장**: 게임 내 `🤖 두뇌 모델 변경` 옵션을 추가하여 언제든 직접 만든 모델과 범용 모델을 자유롭게 변경할 수 있도록 하였습니다.
3. **코드 및 깃허브 배포**: 관련 모든 변경 사항(`LocalAI.js`, `LocalAIUi.js`)은 깃허브 메인 저장소와 로컬 웹 서버에 전면 반영되었습니다.
